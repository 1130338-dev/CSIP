How I investigated

I looked at one system as a whole, then at each part on its own, then at how the parts affect each other.

Conclusion

What I found

No single part decides how fast a system feels. The slowest part sets the pace, and in this system storage and memory held back an otherwise capable processor.

What I recommend

  • Replace the hard disk drive with a solid state drive.
  • Add RAM to reach 16 GB.
  • Remove start-up programs that are not needed.
